# หลายภาษา (ไทย · English · မြန်မာ · ខ្មែរ)

เมนูไอคอนโลก 🌐 บน TopBar และหน้าเข้าสู่ระบบ — จำภาษาไว้ในเบราว์เซอร์ของแต่ละเครื่อง ฟอนต์พม่า/เขมร (Noto Sans) โหลดเมื่อเลือกภาษานั้นเท่านั้น

## ทำงานยังไง
ข้อความไทยในโค้ดเป็นคีย์: `t('หน้าแรก')` → ไทยแสดงตามเดิม ภาษาอื่นดูคำแปลใน `client/src/i18n/{en,my,km}.ts` ข้อความที่ยังไม่มีคำแปลจะแสดงเป็นไทย (ไม่พัง) จึงแปลทีละหน้าได้
เพิ่มคำแปล = เพิ่ม 1 บรรทัดในไฟล์ภาษา + ครอบข้อความด้วย `t(...)` (คอมโพเนนต์ต้องมี `const t = useT();`)

## เฟส 1 (ที่ทำแล้ว)
เมนูซ้าย, แถบบน (ค้นหา/แจ้งเตือน/เมนูผู้ใช้), หน้าเข้าสู่ระบบ, หน้าไฟล์ทั้งหมด/โฟลเดอร์, หน้าแรก, ปุ่มทั่วไป (บันทึก/ยกเลิก/ลบ/แก้ไข ฯลฯ) — 79 ข้อความ

## ยังไม่ได้ทำ (เฟสต่อไป)
- หน้าอื่นทั้งหมด (ตารางข้อมูล, ฟอร์ม, แดชบอร์ด, ตั้งค่า, PDF designer, InkCode ฯลฯ) ~2,000 ข้อความ ใน 108 ไฟล์ — ยังเป็นไทย
- ข้อความ error/แจ้งเตือนจากเซิร์ฟเวอร์ (ภาษาไทยในโค้ด API) และชื่อ/ข้อมูลที่ผู้ใช้กรอกเอง (ไม่แปล)
- **PDF**: ฟอนต์ใน PDF (Sarabun/Prompt/Kanit) ไม่มีอักษรพม่า/เขมร ข้อความพม่า/เขมรใน PDF จะไม่แสดง ต้องฝังฟอนต์เพิ่ม
- **คำแปลพม่า/เขมรเป็นของผู้ช่วย AI ไม่ได้ผ่านเจ้าของภาษา** ควรให้พนักงานที่ใช้ภาษานั้นตรวจและแก้ในไฟล์ `my.ts` / `km.ts` ก่อนใช้งานจริง
