# บัญชีผู้ใช้ · Tag · ลิงก์แชร์ · หน้าต่าง (Modal)

## 1. ลิงก์ของไฟล์ / โฟลเดอร์

ปุ่ม **แชร์** → ช่องบนสุด **ลิงก์ของไฟล์นี้ / ลิงก์ของโฟลเดอร์นี้** → **คัดลอกลิงก์** (เช่น `https://dochub.qcqrxdigital.dpdns.org/files/<id>`)

- ผู้รับกดลิงก์แล้วยังไม่เข้าสู่ระบบ → ไปหน้า `/login?next=/files/<id>` → เข้าสู่ระบบ (รหัสผ่าน หรือ Microsoft) → เปิดไฟล์นั้นให้เลย
- เข้าสู่ระบบอยู่แล้ว → เปิดไฟล์เลย
- ยังไม่มีสิทธิ์ → เห็นชื่อไฟล์/โฟลเดอร์ + ฟอร์ม **ขอสิทธิ์** (ผู้ดูแลไฟล์ได้รับแจ้งเตือน) · โฟลเดอร์ที่มองเห็นแต่ยังไม่มีสิทธิ์มีปุ่ม **ขอสิทธิ์โฟลเดอร์นี้**
- ลิงก์นี้ไม่ให้สิทธิ์เอง — ให้สิทธิ์ผู้ใช้หรือ Tag ในหน้าต่างเดียวกัน (ต่างจาก "แชร์ด้วยลิงก์" ที่ให้คนไม่มีบัญชีดูได้)

## 2. ขอสร้างบัญชี (สมัครเอง หรือ Microsoft)

**ผู้ขอ:** หน้าเข้าสู่ระบบ → **ขอสร้างบัญชี** → กรอกชื่อ อีเมล ชื่อผู้ใช้ รหัสผ่าน เลือก **ระดับที่ต้องการ** (Viewer / User / Master / Admin) และแผนก/เหตุผล → ส่งคำขอ
หรือกดปุ่ม **Microsoft** (ที่หน้าเข้าสู่ระบบหรือหน้าขอสร้างบัญชี) → บัญชี Microsoft ที่ยังไม่มีในระบบจะมาที่ฟอร์มเดียวกัน (ชื่อ/อีเมลจาก Microsoft) เลือกระดับแล้วส่ง

**Admin:** ได้รับการแจ้งเตือน + ตัวเลขที่เมนู **จัดการผู้ใช้** → แท็บ **คำขอสร้างบัญชี**
- เห็นระดับที่ผู้ใช้ขอ → **อนุมัติ** แล้วเลือก **ระดับที่ให้จริง** (ตั้งต้น = ตามที่ขอ) + ใส่ Tag ได้เลย → สร้างบัญชีทันที
- **ปฏิเสธ** พร้อมเหตุผลได้ (ผู้ขอส่งใหม่ได้)
- อนุมัติแล้วผู้ขอเข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านที่ตั้งไว้ หรือด้วย Microsoft (ชื่อผู้ใช้สร้างจากอีเมล)

### เปิดปุ่ม Microsoft (ทำครั้งเดียว — ปุ่มขึ้นเมื่อตั้งค่าครบ)

1. https://portal.azure.com → **Microsoft Entra ID** → **App registrations** → **New registration**
   - Name: `DocHUB`
   - Supported account types: เฉพาะบัญชีบริษัท = *Accounts in this organizational directory only* · ทุกบัญชี Microsoft (รวม Outlook/Hotmail ส่วนตัว) = *…any organizational directory … and personal Microsoft accounts*
   - Redirect URI → **Web**: `https://dochub.qcqrxdigital.dpdns.org/api/auth/oauth/microsoft/callback`
2. หน้า Overview จด **Application (client) ID** และ **Directory (tenant) ID**
3. **Certificates & secrets** → **New client secret** → คัดลอกช่อง **Value** (เห็นครั้งเดียว — อย่าส่งในแชต)
4. `server\.env` บน server:
   ```
   PUBLIC_URL=https://dochub.qcqrxdigital.dpdns.org
   MS_CLIENT_ID=<Application (client) ID>
   MS_CLIENT_SECRET=<Value จากข้อ 3>
   MS_TENANT=<Directory (tenant) ID>      (เลือก "ทุกบัญชี Microsoft" ในข้อ 1 → ใส่ common)
   ```
5. `pm2 restart dochub` (แก้ `.env` ต้องรีสตาร์ตเอง — PM2 ดูแค่ `server/dist`)

ปุ่ม Microsoft ใช้ผ่านลิงก์ public (`https://dochub.qcqrxdigital.dpdns.org`) — ถ้าเปิดผ่าน `http://172.48.0.116:…` Microsoft จะส่งกลับไปที่โดเมน public
`OAUTH_ALLOWED_DOMAINS=thaiunion.co.th` (ตัวอย่าง) จำกัดอีเมลที่ใช้ปุ่ม Microsoft ได้ · `OAUTH_AUTO_CREATE=true` = สร้างบัญชีให้เลยไม่ต้องรออนุมัติ (ไม่แนะนำ)

## 3. Tag

**จัดการผู้ใช้ → Tag** (Admin): สร้าง Tag (ชื่อ สี คำอธิบาย) → **สมาชิก** → ค้นหาผู้ใช้เพื่อเพิ่ม / เอาออก
ผู้ใช้ 1 คนมีได้หลาย Tag — แก้ได้จากหน้าต่าง **แก้ไขผู้ใช้** หรือตอนอนุมัติคำขอสร้างบัญชี · หน้าผู้ใช้กรองตาม Tag ได้

**แชร์ให้ Tag**: ปุ่มแชร์ของไฟล์/โฟลเดอร์ → **แชร์ให้ Tag** → เลือก Tag + ระดับ (ดู / แก้ไข / จัดการ) + วันหมดอายุ → เพิ่ม
- ทุกคนที่มี Tag นั้นเข้าถึงได้ทันที (ได้รับแจ้งเตือน) · คนที่ถูกเพิ่มเข้า Tag ทีหลังก็ได้สิทธิ์ด้วย เอาออกจาก Tag = สิทธิ์นั้นหายทันที
- แชร์ให้ Tag ที่โฟลเดอร์ → สืบทอดไปโฟลเดอร์ย่อยและไฟล์ข้างใน (เหมือนแชร์ให้ผู้ใช้)
- ระดับสูงสุดยังจำกัดตามบทบาท: Viewer ดูได้อย่างเดียว · User ไม่เกิน "แก้ไขข้อมูล"
- ลบ Tag = เอาออกจากทุกคน + ยกเลิกสิทธิ์ที่แชร์ให้ Tag นั้นทั้งหมด

## 4. หน้าต่าง (Modal)

แตะนอกกรอบ หรือกด Esc **ไม่ปิด** หน้าต่างแล้ว (กันข้อมูลที่พิมพ์ไว้หาย) — ปิดได้จากปุ่ม ✕ / ยกเลิก / ปุ่มของหน้าต่างเท่านั้น
(ตั้งที่ `client/src/components/ui/Modal.tsx` ใช้กับทุกหน้าต่าง · หน้าดูรูปเต็มจอยังแตะเพื่อปิดได้)

## ทดสอบแล้ว / ยังไม่ได้ทดสอบ

- ทดสอบ (SQL Server 2022 + เบราว์เซอร์จำลอง PC และ iPhone): API 44 รายการผ่าน (Tag: สร้าง/ชื่อซ้ำ/สมาชิก/แชร์โฟลเดอร์ให้ Tag แล้วเปิดไฟล์ข้างในได้/จำกัดตามบทบาท/หมดอายุ/เอาออกจาก Tag แล้วเข้าไม่ได้/ลบ Tag · คำขอสร้างบัญชี: ส่ง/ซ้ำ/แจ้ง Admin/เข้าก่อนอนุมัติไม่ได้/อนุมัติด้วยระดับอื่น/ใส่ Tag/ปฏิเสธแล้วขอใหม่/Microsoft ด้วย token จำลอง) · ลิงก์ตอนยังไม่เข้าสู่ระบบ → login → กลับมาที่ไฟล์ (รวมรีเฟรชหน้า login) · Modal แชร์และเพิ่มแถว: แตะนอกกรอบ/Esc ไม่ปิด ✕/ยกเลิก ปิด · ลิงก์โฟลเดอร์ที่ไม่มีสิทธิ์ (ทั้ง SHOW_LOCKED_ITEMS=true/false)
- ยังไม่ได้ทดสอบ: ปุ่ม Microsoft กับ Microsoft จริง (ต้องลงทะเบียนแอปตามข้อ 2 ก่อน — ทดสอบด้วย token จำลองแทน), server จริง, มือถือเครื่องจริง
