# InkCode — ระบบออกโค้ดนอกแผน (แทนไฟล์ Excel 2 ไฟล์)

## โครงสร้างที่สร้างให้ (โฟลเดอร์ `InkCode`)
| ไฟล์ | ชีต | หน้าที่ |
|---|---|---|
| InkCode - รหัสอ้างอิง | ปี · เดือน · วัน · ไลน์ · กะ · ปฏิทิน | ตาราง Ref เดิม (รหัสปี, รหัสเดือน A-M, รหัสวัน, รหัสไลน์, Julian ฯลฯ) แก้ได้ที่นี่ที่เดียว |
| InkCode - Master Database | ฐานข้อมูล (2,896 แถว) | 1 แถว = รหัสเอกสาร + Market พร้อม **แบบโค้ดแถว 1-4**, SAP, วัสดุ ฯลฯ |
| InkCode - ใบออกโค้ดนอกแผน | Worksheet | พนักงานกรอก วันที่ผลิต · ไลน์ · กะ · รหัสเอกสาร · Market → ระบบเติมลูกค้า/ชนิด/SAP และ **Code Format แถว 1-4** ให้เอง |

PDF "ใบออกโค้ดนอกแผน 4 ส่วน": เลือกแถวใน Worksheet → ส่งออก PDF → ได้ 4 สำเนา (คั่นเส้นประ) มีกริด 40 ช่อง × 4 บรรทัด และช่องลงชื่อ

## แนวคิด: แบบโค้ด (template) แทนสูตรเป็นสิบแบบ
ใน Excel แต่ละสินค้าใช้สูตรต่างกัน (BBE:, BEST BY, BC…BB, Julian ฯลฯ) DocHUB เก็บเป็น **แบบข้อความ** เช่น `{P} S{YC}{MC}{DC}S{LC}`
ฟังก์ชัน `FILL(แบบ, ตัวแปร)` แทนค่าให้ตามวันที่ผลิต/ไลน์ของแถว
ตัวแปร: `{P}` Short code · `{F}` รหัสเอกสาร · `{Y}` `{Y+3}` `{YY}` `{Y1}` ปี · `{D}` `{DD}` `{DD-1}` วัน · `{Mo}` `{MM}` เดือน · `{YC}` รหัสปี · `{MC}` รหัสเดือน · `{MON}` JAN · `{M2}` JA · `{DC}` รหัสวัน · `{LC}` `{LC2}` `{PF}` รหัสไลน์ · `{SC2-4}` รหัสกะ · `{K2…K10}` ปฏิทิน (`{K6L3}` 3 ตัวแรก, `{K6R1}` 1 ตัวท้าย, `{K3-1}` วันก่อนหน้า)
เพิ่มสินค้าใหม่ = เพิ่ม 1 แถวใน "ฐานข้อมูล" แล้วพิมพ์แบบโค้ดของมัน

## วิธีติดตั้ง (บนเครื่องที่รัน DocHUB)
```
git pull && cd server && npm install
set DOCHUB_URL=http://172.48.0.116:4000/api
set DOCHUB_USER=<บัญชี master หรือ admin>
set DOCHUB_PASSWORD=<รหัสผ่าน>
npx ts-node --transpile-only scripts/seedInkCode.ts --dry     (ดูก่อนว่าจะสร้างอะไร)
npx ts-node --transpile-only scripts/seedInkCode.ts
```
สคริปต์เรียก API ปกติ (ตรวจสิทธิ์/บันทึก audit เหมือนใช้หน้าเว็บ) ไม่แตะ SQL ตรง และไม่เขียนทับ — ถ้ามีไฟล์ชื่อเดียวกันในโฟลเดอร์จะข้าม
ข้อมูลอยู่ใน `scripts/inkcode/data/*.json` สร้างจาก Excel ด้วย `python3 scripts/inkcode/extract.py "<Master_Database.xlsx>" [รหัสผ่านไฟล์]` (ต้อง `pip install msoffcrypto-tool openpyxl`)

## สิ่งที่ต้องตรวจก่อนใช้จริง
1. **790 จาก 2,896 แถว (27%) แปลงสูตร Code Format เป็นแบบโค้ดอัตโนมัติไม่ได้** — ช่อง "แบบโค้ดแถว" ของแถวนั้นว่าง สูตรเดิมอยู่ในคอลัมน์ "สูตรเดิมที่ต้องตรวจ" (กรองไม่ว่าง) ส่วนใหญ่อ้างชีต `up date Ref2026`, วันหมดอายุที่คำนวณซ้อนจากปฏิทิน หรือลิงก์ไปไฟล์ Master รุ่นเก่า ต้องให้คนรู้กฎพิมพ์แบบโค้ดเอง
2. ข้อความที่พิมพ์ไว้ตรง ๆ ใน Excel (เช่น `COMPLEMENTARY CAT FOOD NW:55g`) ถูกเก็บเป็นแบบโค้ดที่ไม่มีตัวแปร
3. **คีย์ซ้ำ 114 คู่** (รหัสเอกสาร + Market) — LOOKUP ใช้แถวแรก ตรวจว่าแถวไหนถูก
4. สูตรเดิมใช้ `DAY(วันที่-1)` คู่กับ `MONTH(วันที่)` (วันที่ 1 ของเดือนจะได้วันสุดท้ายของเดือนก่อนคู่กับเดือนปัจจุบัน) DocHUB ทำตามเดิม ถ้าเป็นบั๊ก ต้องแก้แบบโค้ดเอง
5. ไม่ได้ย้ายชีต Can/Pouch/Cup ของไฟล์ Pet Food (แบบฟอร์มพิมพ์ที่พิมพ์ตัวอักษรไว้ด้วยมือรายไลน์) และชีต `up date Ref2026`, `MARS-STD`, `PFC80`, `%ทวนสอบ`
6. ลิงก์ภายนอกของ Excel ไม่มีอีกต่อไป — ข้อมูลทั้งหมดอยู่ใน DocHUB

## ทดสอบแล้ว / ยังไม่ได้ทดสอบ
- ทดสอบ: สูตรทั้งหมดคอมไพล์และคำนวณถูกเทียบกับกฎ Excel ด้วยตาราง Ref จริง (รหัสปี/เดือน/วัน/ไลน์, BBE, MID), สคริปต์สร้างข้อมูลผ่าน API จำลองที่ตรวจโครงสร้างคำขอด้วย schema จริง, บล็อกกริด 40 ช่อง
- ยังไม่ได้ทดสอบ: การรันบน SQL Server จริง, เทียบกับ Excel ทีละแถวด้วยวันที่จริง, หน้าตา PDF ในเบราว์เซอร์ (ขนาดตัวอักษร/ช่องกริด)

## เพิ่ม/แก้ข้อมูล (ทุกอย่างอยู่ในไฟล์บนเว็บ ไม่มีอะไรซ่อนหลังบ้าน)
| อยากทำ | ทำที่ไหน |
|---|---|
| สินค้า/รหัสเอกสารใหม่ | `InkCode - Master Database` › ฐานข้อมูล › เพิ่มแถว (รหัสเอกสาร, Market, ลูกค้า, SAP, Short Product Code, **แบบโค้ดแถว 1–4**) |
| ไลน์ใหม่ / รหัสปีใหม่ / กะ | `InkCode - รหัสอ้างอิง` › ชีตไลน์ / ปี / กะ |
| ออกโค้ดประจำวัน | `InkCode - ใบออกโค้ดนอกแผน` › Worksheet › เพิ่มแถว (เลือกไลน์ กะ รหัสเอกสาร Market จากรายการ) |
| ดูว่าแบบโค้ดแต่ละตัวให้ผลอะไร | ฐานข้อมูล › คอลัมน์ "ตัวอย่างโค้ดแถว 1–4" (คำนวณจากวันที่/ไลน์ในชีต "ตัวอย่าง" ของไฟล์รหัสอ้างอิง — แก้วันที่ตรงนั้นได้) |
| ดูว่า `{P}` `{YC}` ฯลฯ มาจากไหน | ฐานข้อมูล › ชีต "คู่มือตัวแปร" (ไฟล์/ชีต/คอลัมน์ต้นทางของทุกตัวแปร) และคำอธิบายที่หัวคอลัมน์ "แบบโค้ดแถว" |

ถ้าไลน์ที่พิมพ์ไม่ตรงกับชื่อในชีตไลน์ (เช่นพิมพ์ `line A` แต่ในตารางคือ `Auto A`) รหัสไลน์ `{LC}` จะว่าง — Worksheet จึงใช้ช่องเลือกจากรายการแทนการพิมพ์เอง

## ถ้าสร้างชุดแรกไปแล้ว (เวอร์ชันก่อนมี dropdown / ตัวอย่างโค้ด / คู่มือ)
สคริปต์ไม่เขียนทับของเดิม: ลบ 3 ไฟล์ใน InkCode (ไปถังขยะ) แล้วรัน `seedInkCode.ts` ใหม่ ข้อมูลที่เคยกรองใน Worksheet จะหาย (ถ้ามีข้อมูลจริงแล้ว ให้ส่งออกเป็น Excel เก็บไว้ก่อน)
