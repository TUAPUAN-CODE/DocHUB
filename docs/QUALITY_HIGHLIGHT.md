# Quality Hilight — Note การผลิต (แทนไฟล์ Excel QUALITY HIGHLIGHT)

## สิ่งที่สร้างให้

```
Quality Hilight/                      (โฟลเดอร์)
└── Master/                           (โฟลเดอร์ย่อย)
    └── Quality Hilight - Master      (ไฟล์ · ชีต Master · แดชบอร์ด "Quality Hilight")
```

| คอลัมน์ในชีต Master | ชนิด | หมายเหตุ |
|---|---|---|
| Sub Doc No. | ข้อความ (บังคับ) | หนึ่ง Sub Doc No. มีได้หลายแถว (หลาย Short Code) |
| Material | ข้อความ | |
| Short Code | ข้อความ | |
| ให้Spread | ข้อความยาว | Note ที่ต้องแจ้ง / ควบคุม |
| รูปภาพ | รูปภาพ | ใส่ได้หลายรูปต่อแถว (ถ่ายจากมือถือหรือเลือกไฟล์) — แสดงในแดชบอร์ด |
| วันที่ Update ข้อมูล | วันที่ | **ระบบเติมให้เอง** ทุกครั้งที่เพิ่ม/แก้แถว (ค่าจาก Excel คงไว้) |
| Updated by | ข้อความ | **ระบบเติมชื่อผู้แก้ไขให้เอง** (ค่าจาก Excel คงไว้) |
| วันที่ Update (ข้อความเดิมใน Excel) | ข้อความยาว | เฉพาะแถวที่ Excel เขียนหลายวันในช่องเดียว เช่น `2/11/2022 2.20/01/2024` (ช่องวันที่ใช้วันล่าสุด) |

แดชบอร์ด **Quality Hilight**: ช่องค้นหา Sub Doc No. / Short Code → แสดงทุกแถวที่ตรง (Sub Doc No. เดียวกันรวมเป็นการ์ดเดียว) พร้อม Material, Short Code, ให้Spread, วันที่/ผู้แก้ และรูป · ด้านขวาแสดง **Rev ล่าสุด และสิ่งที่เปลี่ยน** จาก Rev ก่อนหน้า · บนมือถือวิดเจ็ตเรียงลงมาทีละชิ้นเต็มความกว้าง


- ใช้ API ปกติ (ตรวจสิทธิ์ / บันทึกประวัติเหมือนกรอกผ่านหน้าเว็บ)

## การใช้งาน

**ดูข้อมูล (พนักงาน):** เปิดแดชบอร์ด Quality Hilight → พิมพ์ Sub Doc No. หรือ Short Code (พิมพ์บางส่วนได้) → แตะรูปเพื่อดูเต็มจอ, "ดูทั้งหมด" เพื่ออ่าน Note ยาว

**แก้ไข Master (ผู้ดูแล):**
1. เปิดไฟล์ Quality Hilight - Master → แก้ / เพิ่มแถว / ใส่รูปในคอลัมน์ "รูปภาพ" (เพิ่มได้หลายรูป)
   วันที่ Update และ Updated by เปลี่ยนให้เอง
2. ปุ่ม **Rev.N** บนแถบเครื่องมือจะมีตัวเลข `+จำนวนแถว` ที่แก้ไปแล้วแต่ยังไม่ออก Rev
3. กดปุ่ม → ดูรายการเปลี่ยนแปลง (แก้ไข: ค่าเดิมขีดฆ่าสีแดง → ค่าใหม่สีเขียว · เพิ่มใหม่ · ลบออก) → ใส่หมายเหตุ → **ออก Rev.N+1**
4. แดชบอร์ดแสดง Rev ใหม่ทันที และติดป้าย "แก้ไขใน Rev.N" / "ใหม่ใน Rev.N" ที่แถวที่เปลี่ยน
5. ดู Rev เก่า: เมนู ⋯ ของไฟล์ → "Rev ของชีตนี้" หรือเลือกจาก dropdown ในวิดเจ็ต Rev ของแดชบอร์ด

สิทธิ์: ดูแดชบอร์ด = อ่านไฟล์ได้ · แก้ข้อมูลและออก Rev = เขียนไฟล์ได้ · แก้หน้าแดชบอร์ด = จัดการไฟล์ได้ (แชร์ที่โฟลเดอร์ Quality Hilight)

## ฟีเจอร์ที่ใช้กับไฟล์อื่นได้ด้วย

- **ออก Rev** ทุกชีต: เมนู ⋯ ของไฟล์ → "ออก Rev / ประวัติ Rev ของชีตนี้" (Rev แรกเลือกเลขเริ่มได้) · ตั้งคอลัมน์ที่ใช้เรียกชื่อแถวในรายการเปลี่ยนแปลงได้ในหน้าต่างเดียวกัน
- **คอลัมน์เติมอัตโนมัติ**: ตั้งค่าคอลัมน์วันที่ → "เติมวันที่แก้ไขล่าสุดให้อัตโนมัติ" · คอลัมน์ข้อความ → "เติมชื่อผู้แก้ไขล่าสุดให้อัตโนมัติ"
- **วิดเจ็ตแดชบอร์ด** (กลุ่ม "รายละเอียด"): *ค้นหารายละเอียด* (เลือกคอลัมน์ที่ค้น / หัวข้อ / รายละเอียด / รูป) และ *Rev ล่าสุด*
- **แดชบอร์ดบนมือถือ** (จอกว้าง < 640px, โหมดดู): วิดเจ็ตเรียงลงมาทีละชิ้นแทนการย่อทั้งผืนผ้าใบ

## สิ่งที่สคริปต์จัดการตอนนำเข้า (ดูรายละเอียดของไฟล์จริงจากผล `--dry`)

- แถวที่ไม่มี Sub Doc No. / Material / Short Code แต่มีข้อความ = Note ที่ต่อจากแถวด้านบน → ต่อท้าย Note ของแถวนั้น (ไม่สร้างแถวใหม่)
- Sub Doc No. เดียวกันหลายแถว (หลาย Short Code) → นำเข้าครบทุกแถว แดชบอร์ดรวมเป็นการ์ดเดียว
- วันที่ที่ Excel เขียนเป็นข้อความ (หลายวันในช่องเดียว) → ช่องวันที่ใช้วันล่าสุด ข้อความเดิมอยู่ในคอลัมน์ "วันที่ Update (ข้อความเดิมใน Excel)"
- รูปที่วางใน Excel → ผูกกับแถวที่มุมซ้ายบนของรูปอยู่ (ถ้าอยู่ในแถวต่อของ Note ก็ผูกกับแถวหลัก) · แถวที่เขียนถึงรูปแต่ไม่มีรูปในไฟล์ต้องใส่เพิ่มเอง
- **ไม่ได้นำเข้า**: ชีต `QH` (หน้าค้นหาของ Excel → แทนด้วยแดชบอร์ด), `Special`, `Sheet1`, `Sheet4`

## ทดสอบแล้ว / ยังไม่ได้ทดสอบ

- ทดสอบ (SQL Server 2022 ในเครื่องทดสอบ + ไฟล์ REV.8 จริง): นำเข้าครบทุกแถว + รูป + Rev.8, รันซ้ำแล้วหยุด, แก้ Note → วันที่/ชื่อเปลี่ยนเอง, พิมพ์ลงคอลัมน์เติมอัตโนมัติถูกปฏิเสธ, ป้าย `+1` บนปุ่ม Rev, ออก Rev.9 แล้วรายการเปลี่ยนแปลงถูก (ค่าเดิม → ค่าใหม่), ค้นหาด้วย Sub Doc No. (หลายแถว) และ Short Code บนแดชบอร์ด PC และ iPhone (จำลอง), unit test การเทียบ Rev
- ยังไม่ได้ทดสอบ: บน server จริง (Windows + SQL Server ของบริษัท), มือถือเครื่องจริง, ชีตใหญ่หลายหมื่นแถวกับ Rev (เก็บสำเนาทั้งชีตต่อ Rev)
