# อีเมลแจ้ง Quality Highlight เมื่อนำเข้าแผนผลิต

เมื่อนำเข้าแผนผลิต (วางไฟล์ที่แอป **แผนผลิต** หรือในโฟลเดอร์ InkCode › แผนผลิต) แล้วมี **Doc No** ในแผนที่ตรงกับ **Sub Doc No.** ใน
Quality Highlight - Master ระบบส่งอีเมลหนึ่งฉบับต่อแผน ถึงคนที่ผู้ใช้พิมพ์ไว้ — ตารางรายการในแผน (เวลา · ไลน์ · Product · ประเทศ · Doc No)
พร้อมรายละเอียดจาก Quality Highlight ของแต่ละ Doc No (Material · Short Code · Note ให้Spread · วันที่/ผู้อัปเดต) และลิงก์ไปไฟล์ (ถ้าตั้ง `PUBLIC_URL`)

## ไม่มีเซิร์ฟเวอร์เมล: ปุ่ม "เปิดร่างอีเมล" (ใช้ได้ทันที)

หลังนำเข้าแผนที่มี Doc No ตรงกับ Quality Highlight ใต้ผลนำเข้ามีปุ่ม
- **เปิดร่างอีเมล** — เปิดโปรแกรมอีเมลของเครื่อง (ต้องตั้ง Outlook บนเครื่องเป็นโปรแกรมอีเมลเริ่มต้น) พร้อม To / CC / หัวข้อ ที่ตั้งไว้ในการ์ด · อีเมลสั้นใส่ข้อความครบเลย
  อีเมลยาวระบบคัดลอก "ตาราง" ไว้ให้ แล้วกด Ctrl+V ในหน้าเขียนอีเมลเพื่อวางตาราง (ลิงก์ mailto ยาวเกินไม่ได้)
- **คัดลอกเป็นตาราง** — คัดลอกตารางไว้ วางใน Outlook (ทั้งแบบเว็บและโปรแกรม) ได้ทันที
คนที่นำเข้าเป็นคนกดส่งเอง · ตั้ง To / CC / หัวข้อ ที่การ์ด "อีเมลแจ้ง Quality Highlight" (Master / Admin) ได้โดยไม่ต้องเปิดส่งอัตโนมัติ

## ตั้งค่าส่งอัตโนมัติ (Master / Admin) — หน้า แผนผลิต › การ์ด "อีเมลแจ้ง Quality Highlight"

1. เลือก **ช่องทางส่ง** (ค่าเริ่มต้น SMTP):
   - **SMTP** (ไม่ต้องขอสิทธิ์ Azure) — ใส่เซิร์ฟเวอร์ · พอร์ต · อีเมลผู้ส่ง (From) · ชื่อบัญชี/รหัสผ่าน (เว้นว่างถ้าเซิร์ฟเวอร์ไม่ต้องล็อกอิน เช่น relay ภายใน) ·
     พอร์ต 587 ใช้ STARTTLS เอง, พอร์ต 465 ติ๊ก "เข้ารหัสทั้งการเชื่อมต่อ" · เซิร์ฟเวอร์ภายในที่ใบรับรองเซ็นเอง ติ๊ก "ไม่ตรวจใบรับรอง"
     (Microsoft 365 ต้องให้ IT เปิด SMTP AUTH ให้กล่องนั้น — ถ้าไม่ได้ ใช้ relay ภายในหรือช่องทาง Outlook)
   - **Outlook (Microsoft 365)** — กด **เชื่อม Outlook** แล้วเข้าสู่ระบบ Microsoft ด้วยกล่องที่จะใช้ส่ง (อีเมลอยู่ใน Sent Items) · ต้องตั้งค่า Azure ตามหัวข้อด้านล่าง
2. ใส่ **ถึง (To)** / **สำเนา (CC)** / **หัวข้อ** / **ข้อความนำ** เอง — ใช้ `{date}` วันที่ผลิต · `{count}` จำนวน Doc No ที่ตรง · `{file}` ชื่อไฟล์แผน
3. เปิดสวิตช์ แล้วกด **บันทึก** · ปุ่ม **บันทึกและส่งอีเมลทดสอบ** ส่งตัวอย่างจากข้อมูล Quality Highlight จริงถึงอีเมลผู้ส่งเอง

- แผนเดิม (วันเดียวกัน Doc No ชุดเดียวกัน ผู้รับชุดเดียวกัน) **ไม่ส่งซ้ำ** — เปลี่ยนผู้รับแล้วจึงส่งใหม่ได้
- ถ้าไม่มี Doc No ตรง / ยังไม่ใส่ผู้รับ / Outlook หมดอายุ — ระบบไม่ส่ง และบอกเหตุผลใต้ผลการนำเข้า (การนำเข้าแผนไม่ล้มเหลวเพราะอีเมล)

## ตั้งค่าที่ Azure (เฉพาะช่องทาง Outlook — ครั้งเดียว โดยผู้ดูแล Microsoft 365 ของบริษัท)

ใช้แอป Microsoft เดียวกับการนำเข้าลิงก์ OneDrive (`MS_CLIENT_ID` / `MS_CLIENT_SECRET` / `MS_TENANT` ใน `.env` — ดู docs/CONNECTORS.md)

- **API permissions › Microsoft Graph › Delegated:** เพิ่ม `Mail.Send` และ `User.Read` (กด Grant admin consent ถ้าองค์กรบังคับ)
- Redirect URI เดิม `…/api/connectors/ms/callback` ใช้ต่อได้ ไม่ต้องเพิ่ม
- ตั้ง `PUBLIC_URL` ใน `.env` ถ้าต้องการลิงก์ในอีเมล

## ที่เก็บข้อมูล

ตั้งค่าอยู่ใน `SystemSettings` คีย์ `inkcode.qhMail` · โทเคน Outlook เข้ารหัสไว้ที่ `inkcode.mailSender` และตั้งค่า SMTP (รวมรหัสผ่าน) เข้ารหัสไว้ที่ `inkcode.mailSmtp` (ไม่ส่งกลับไปที่หน้าเว็บ) ·
รายการที่ส่งแล้วที่ `inkcode.qhMail.sent` (300 ล่าสุด)
