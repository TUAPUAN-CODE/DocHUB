# Application (แอป) และการจัดการเมนู

## หน้า Application (เมนูซ้าย)
ไอคอนแอปแบบหน้าจอมือถือ กดเพื่อเปิด · ช่องค้นหาด้านบน (ชื่อแอป / ที่มา) · ปุ่ม ⓘ = รายละเอียด
| แอป | มาจาก | ใครเห็น |
|---|---|---|
| แดชบอร์ดทุกอัน | อัตโนมัติ (ไม่ต้องสร้าง) | คนที่อ่านไฟล์ของแดชบอร์ดได้ |
| แผนผลิต | หน้า นำเข้าแผนผลิต (InkCode) | role ที่ได้สิทธิ์ "นำเข้าแผนผลิต" ในหน้า จัดการสิทธิ์ |
| แอปที่ Admin เพิ่ม | ปุ่ม **เพิ่ม App**: ไฟล์ / โฟลเดอร์ / แดชบอร์ด / ลิงก์เว็บ | คนที่เปิดไฟล์/โฟลเดอร์นั้นได้ (ลิงก์เว็บ = ทุกคน) |

* **ประเภท (Type)**: ปุ่มกรองใต้ช่องค้นหา (ทั้งหมด · QC · … · ไม่มีประเภท) — หน้าเปิดที่ประเภทค่าเริ่มต้น (★, เริ่มต้น = QC; Admin กด "ตั้ง … เป็นค่าเริ่มต้น") · พิมพ์ค้นหา = ค้นทุกประเภท · ตั้งประเภทของแอปที่ ⓘ › ตั้งค่าแอป › ประเภท (พิมพ์ใหม่ได้) · `database/31_app_types.sql` ใส่ QC ให้ dashboard Quality Highlight Line / Incoming, MD Record Problem, Anatomy-Manual
* **ขนาดไอคอน**: ปุ่ม เล็ก / กลาง / ใหญ่ / ใหญ่มาก ข้างช่องค้นหา (จำไว้ในเบราว์เซอร์ของแต่ละคน)
* เปิดแอปแล้ว แถบซ้ายยังไฮไลต์ Application และลูกศรกลับของแดชบอร์ดพากลับหน้า Application
* **รายละเอียด (ⓘ)**: ดึงข้อมูลจากโฟลเดอร์/ไฟล์ไหน และใครเข้าถึงได้ (เจ้าของ, แชร์ไฟล์, แชร์ผ่านโฟลเดอร์, Tag, ผู้สร้างโฟลเดอร์) — Admin/Root เปิดได้ทุกไฟล์
* **ตั้งค่าแอป** (Admin/Root, แท็บในหน้ารายละเอียด): ชื่อ, อัปโหลดรูปไอคอน, สี, คำอธิบาย, ให้เห็นเฉพาะ role, ให้เห็นเฉพาะคนใน Tag, ลำดับ, ซ่อน · ปุ่ม "คืนค่าเริ่มต้น" (แอปอัตโนมัติ) / "ลบแอป" (แอปที่เพิ่มเอง ไฟล์ต้นทางไม่ถูกลบ)
* การจำกัด/ซ่อนแอป ไม่เปลี่ยนสิทธิ์ของไฟล์ (คนที่มีสิทธิ์ยังเปิดไฟล์จากเมนูไฟล์ได้) · Admin/Root เห็นทุกแอปเสมอ (สวิตช์ "แสดงแอปที่ซ่อน")
* ข้อมูลอยู่ในตาราง `Apps` (`database/29_apps.sql`): แถวมีเฉพาะแอปที่ถูกตั้งค่าหรือเพิ่มเอง; API `/api/apps`, `/api/apps/details?key=`, `PUT|DELETE /api/apps/item?key=` (Admin), `POST /api/apps` (Admin)

## เมนูซ้าย: แดชบอร์ด และ นำเข้าแผนผลิต
ย้ายเข้าไปเป็นแอปในหน้า Application (ไม่แสดงในแถบซ้าย) — หน้าเดิม `/dashboards`, `/inkcode/plan` ยังเปิดได้ และสิทธิ์ยังตั้งที่หน้า จัดการสิทธิ์ (`notInNav` ใน `pageAccess/registry.ts` + `lib/pages.tsx`)

## จัดการสิทธิ์ (Admin และ Root)
* ติ๊กว่าแต่ละ role เห็นเมนูไหน (เหมือนเดิม) — ตอนนี้ **Admin ใช้ได้เท่า Root** (ยกเว้นแถว Root ที่เห็นทุกเมนูเสมอ)
* เมนู จัดการสิทธิ์ ล็อกให้ Admin เห็นเสมอ (กันล็อกตัวเองออก)
* **ลำดับเมนู**: ลูกศร ↑ ↓ หน้าชื่อเมนูในกลุ่ม "เมนูด้านซ้าย" → บันทึก (SystemSettings `pageOrder`)
* **หน้าแรก** ปิดได้ต่อ role แล้ว — role ที่ไม่เห็นหน้าแรก เข้า `/` จะไปเมนูแรกที่เห็นแทน (ตั้งค่า เห็นเสมอ)
* กลุ่ม "เปิดจากหน้า Application": แผนผลิต / แดชบอร์ด ไม่อยู่ในแถบซ้าย — ติ๊ก = role นั้นเห็นแอปและเปิดหน้านั้นได้
* **เปลี่ยนชื่อเมนู**: ช่องใต้ชื่อแต่ละเมนู (ว่าง = ชื่อเดิม) → บันทึก → เมนูของทุกคนเปลี่ยนทันที (SystemSettings `pageLabels`)

## สมัครบัญชี
User / Viewer สมัครแล้วได้บัญชีทันที (ไม่ต้องรออนุมัติ — Admin ได้แจ้งเตือน "มีบัญชีใหม่" และเปลี่ยนระดับ / ปิดบัญชีได้ที่ จัดการผู้ใช้) · Master / Admin ยังรอ Admin อนุมัติเหมือนเดิม (`AUTO_ROLES` ใน `modules/accountRequests/routes.ts`)

## ไอคอนระบบ
ตั้งค่า › ชื่อและไอคอนระบบ › **อัปโหลดไอคอน** (Admin): เบราว์เซอร์ย่อรูปเป็น PNG สี่เหลี่ยมจัตุรัส 512 / 192 / 180 px (ใส่สีพื้นหลังและขอบได้) แล้วเซิร์ฟเวอร์ใช้แทนไฟล์ไอคอนเดิม
`/icons/icon-192.png`, `/icons/icon-512.png`, `/icons/icon-maskable-512.png`, `/apple-touch-icon.png` (manifest ไม่ต้องแก้) + แท็บ browser, เมนูซ้าย, หน้าเข้าสู่ระบบ — SystemSettings `app_icon` · ปุ่ม "ใช้ไอคอนเดิมของระบบ" = กลับเป็นค่าเดิม
