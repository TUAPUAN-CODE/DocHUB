## ชีต หลังคัดมือ (ปรับให้ลงง่ายขึ้น ผลเหมือนเดิม)

| คอลัมน์ | หมายเหตุ |
|---|---|
| วันที่ · กะ (DS/NS) · เวลา · โรงผลิต (ตั้งต้น PF1) · ลูกค้า (ทั่วไป) · พื้นที่ (Tomra) · Batch · Code · รอบอบ | |
| จำนวน (คอลัมน์ J เดิม) | หัวคอลัมน์ J ใน Excel อ่านไม่ออก — แก้ชื่อได้ที่ ตั้งค่าคอลัมน์ |
| No.1 · No.2 (<1 / 1-2 / >2 cm) · No.3 (<1 / 1-2 / >2 cm) · No.4 – No.10 · เกล็ด · หนัง | ตัวเลข ตั้งต้น 0 · คำอธิบายบอกเกณฑ์ (ห้ามพบ / ยอมรับไม่เกิน) |
| รวมก้าง (สูตร) | No.1–No.10 ไม่รวมเกล็ด/หนัง |
| ก้าง/100kg (สูตร) | รวมก้าง × 100 / 0.5 — ค่าเฉลี่ยของคอลัมน์ = pcs/100kg ของช่วงที่เลือก (สูตรเดียวกับ Excel: ก้าง × 100 / (คัน × 0.5)) |
| PASS / Not Pass · TOMRA/LEO · Remark | |

ต่างจาก Excel: ก้างแต่ละส่วนเหลือ **ช่องเดียว** (เดิมมีช่องจำนวน + ช่อง Rec. และ Excel รวมสองช่อง SUM(K:L)) — ข้อมูลเดิมนำเข้าเป็นผลรวมแล้ว

แบบฟอร์ม (+ เพิ่มแถว) 3 ช่องต่อบรรทัด · บนคอมพิมพ์ในแถว * ล่างสุดได้

## แดชบอร์ด Anatomy-Manual

ตัวกรอง ช่วงวันที่ · กะ · โรงผลิต · Code · Batch → KPI จำนวนคัน / ก้างรวม / pcs/100kg / เกล็ด / หนัง ·
**รูปปลา** พร้อมจำนวนก้างแต่ละส่วน (No.2 / No.3 แยกขนาด) · ก้างแต่ละส่วนแยกกะ · **เทรนด์ก้างที่พบ vs จำนวนคัน ต่อวัน (DS, NS)** ·
pcs/100kg ต่อวันแยกกะ · รายเดือนแยกกะ · Pareto Code · ตารางสรุปรายวัน / รายเดือน / แต่ละส่วน (คลิกหัวคอลัมน์เพื่อเรียง)
