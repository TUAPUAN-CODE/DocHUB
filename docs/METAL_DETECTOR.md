## ทำครั้งเดียวหลังติดตั้ง (Admin)

1. **จัดการผู้ใช้ → Tag → MD → สมาชิก**: ใส่ชื่อพนักงานคุมเครื่อง / QC ที่ลงชื่อในใบตรวจ
   (ช่อง พนักงานคุมเครื่อง · Checked By (QC staff) · Checked By ของรายการ เลือกได้เฉพาะคนใน Tag MD)
2. ช่อง **Reviewed By (QC Section Manager)** เลือกได้จากผู้ใช้ทุกคน — ถ้าต้องการจำกัด: ตั้งค่าคอลัมน์ → รายชื่อผู้ใช้ในระบบ → เลือก Tag

## การใช้งาน (ดูภาพทีละขั้นที่เมนู คู่มือ → ใบตรวจ Metal Detector)

1. ชีต **หัวเอกสาร** → **+ เพิ่มแถว** → กรอกหัวกระดาษ → บันทึก (ได้เลขที่ใบตรวจ MD-YYMMDD-NNN อัตโนมัติ)
2. หน้าต่าง **รายการ** ของใบนั้นเปิดให้เอง → **+ เพิ่มรายการ** ทุกครั้งที่ตรวจ
   - วันที่ · กะ · หมายเลขเครื่อง เติมจากหัวเอกสาร
   - **ความถี่ (F)** เลือกได้หลายข้อในช่องเดียว (F0–F7)
   - **โปรแกรม / Sensitivity** แสดงเฉพาะโปรแกรมของเครื่องนั้น พร้อมค่าที่ควบคุม เช่น `038 Chunk PET-01 (Fe 3.5 / SUS 6.0)` หรือ `001 Chunk (ML1 9.0 / ML2 7.0 / ML3 9.0 / ML4 9.0)`
   - Fe · Non Fe · SUS · Large test piece · Result · รอบ A 1-2 · Object · รอบ B 1-3: **✓** ผลผ่าน · **x** ผลไม่ผ่าน · **-** ไม่พบปัญหา · **∙** ไม่ตรงกับรอบการตรวจ (ช่องผลการตรวจจับวัตถุดิบตั้งต้นเป็น -)
3. เปิดใบเดิม: ชีตหัวเอกสาร → กดรูปตาหน้าแถว → **รายการในแถว** · ค้นหาใบได้จากเมนู **Search**
4. ใบกับรายการเชื่อมกันอย่างไร: ชีตหัวเอกสารมีคอลัมน์ **รายการตรวจ** หน้าเลขแถว (“N รายการ” กดเพื่อเปิด) · ชีตรายการตรวจมีคอลัมน์
   **หัวเอกสาร** บอกเลขที่ใบของแต่ละรายการ (กดเพื่อไปที่ใบนั้น) — ข้อมูลเชื่อมกันจริงในฐานข้อมูล (`RowLinks`) ไม่ได้อาศัยค่าที่พิมพ์ซ้ำ
5. **พิมพ์ PDF**: คลิกแถวของใบ (เลือกหลายใบได้ ใบละหน้า) → **ส่งออก → PDF — ใบตรวจ F3QCPF06 (แบบฟอร์ม Excel A4 แนวตั้ง)** —
   หน้าตาตามแบบฟอร์ม Excel F3QCPF06 แก้ไขครั้งที่ 4: หัวบริษัท · วันที่/กะ/เครื่อง/ฝาล็อค/Speed · Test piece/Belt stop/Alarm · ความถี่ F0–F7 ·
   ตาราง 2 กลุ่มหัวข้อ 19 คอลัมน์ **33 บรรทัด** (มีเฉพาะรายการของใบนั้น เกิน 33 รายการขึ้นหน้าใหม่) · หมายเหตุและเงื่อนไขรอบ A/B · Test pieces ·
   พนักงานคุมเครื่อง · Checked By / Reviewed By · กล่องควบคุมเอกสาร (ชื่อผู้จัดทำ/ผู้อนุมัติ เว้นไว้ — พิมพ์เพิ่มได้ที่ **… → รูปแบบ PDF** ครั้งเดียว)
   - **สำเนาของไฟล์ใบตรวจ** (เช่น Data / 2026 / November / F3QCPF06): ทำสำเนาหลังจากนี้ได้รูปแบบ PDF ติดไปเอง · สำเนาที่ทำไว้ก่อน
     ได้รูปแบบจาก seed `zz_md_f3qcpf06_pdf_v3_copies.sql` (ไฟล์ที่มีชีต หัวเอกสาร + รายการตรวจ ของ F3QCPF06 และยังไม่มีแบบ Excel A4) ·
     ทำเองได้ที่ **… → ออกแบบรูปแบบ PDF → คัดลอกจากไฟล์อื่น** → เลือกไฟล์ใบตรวจต้นฉบับ
   - seed `zz_md_f3qcpf06_pdf_v2.sql`: ถ้ารูปแบบเดิม (แนวนอน จาก `zz_md_f3qcpf06_pdf.sql`) ไม่มีใครแก้ → แทนที่ · ถ้าแก้ไว้ → เพิ่มแบบใหม่ต่อท้าย
   - ไฟล์ที่ออก Rev ไว้แล้วจะเห็นการเปลี่ยนรูปแบบรอออก Rev ถัดไป — ออก Rev หรือปล่อยไว้ก็ได้

## สำหรับนักพัฒนา

- โครงสร้างสร้างด้วย `server/scripts/buildMetalDetector.ts` (ผ่าน API บนฐานข้อมูลทดสอบ, ข้อมูลโปรแกรมจาก JSON ที่ไม่ได้เก็บใน repo)
  แล้ว `server/scripts/exportSeedSql.ts --file-id <โปรแกรม>,<ใบตรวจ> --folder "DAILY METAL DETECTOR SENSITIVITY TEST REPORT" --sub Data --rename-from "Metal Detector Report" --tags MD --grant-tag MD:write`
- รูปแบบ PDF สร้างด้วย `server/scripts/mdPdfTemplate.cjs > database/seed/zz_md_f3qcpf06_pdf_v2.sql` (ชื่อขึ้นต้น zz_ ให้รันหลัง seed ใบตรวจ) ·
  ตาราง PDF มีหัวข้อกลุ่มหลายชั้น (`headerGroups`), จำนวนบรรทัดขั้นต่ำ (`minRows`) และ “แสดงเฉพาะคำแรก” ต่อคอลัมน์ (`firstWord`) ใช้กับไฟล์อื่นได้ ·
  ตาราง PDF แบบ “ฟอร์มต่อแถว” เลือก **เฉพาะรายการของแถวนี้** (`rowLines`) ได้กับทุกไฟล์ที่มีรายการย่อย
- ความสามารถทั่วไปที่ใช้: ตัวเลือกจากรายชื่อผู้ใช้ตาม Tag (`validation.lookup.users.tag`), รายการย่อยแบบกรอกฟอร์ม (`settings.lines.entry = 'form'`), ชีตรวม + ตัวเลือกที่กรองตามเครื่อง (lookup parent)
