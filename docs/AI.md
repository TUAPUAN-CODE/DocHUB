# ผู้ช่วย AI (Right bar)

ปุ่ม **AI** บน TopBar เปิดแผงด้านขวา — ใช้ API key ของผู้ใช้เอง (Gemini มีโควตาฟรี / Claude / OpenAI และบริการที่เข้ากันได้ เช่น Groq, OpenRouter, Ollama ใส่ Base URL)

- ตั้ง key: ปุ่มเฟืองในแผง → เก็บเข้ารหัส AES-256-GCM บนเซิร์ฟเวอร์ (ตาราง `AiKeys`) ไม่ส่งกลับเบราว์เซอร์
- สรุปข้อมูล: AI เรียกเครื่องมือ `list_files → get_sheet_schema → aggregate / query_rows` (สูงสุด 30 แถว/ครั้ง)
- สร้างแดชบอร์ด: ในหน้า Dashboard พิมพ์ว่าต้องการกราฟอะไร → `create_dashboard` / `add_widgets` (bar, line, area, pie, doughnut, scatter, pareto, histogram, kpi, table, text) วางตำแหน่งอัตโนมัติ แล้วหน้าจอโหลดใหม่ให้
- ทุกเครื่องมือทำงานด้วยสิทธิ์ของผู้ใช้คนที่คุยอยู่ (ต้องมีสิทธิ์ manage ถึงจะเพิ่มกราฟได้) และถูกบันทึกใน audit (`ai_chat`, `dashboard_update`)

## ข้อควรรู้ด้านข้อมูล
- ข้อมูลที่ AI ขอดู (แถวตัวอย่าง / ตัวเลขสรุป) **ถูกส่งออกไปยังผู้ให้บริการที่เลือก** (Google / Anthropic / OpenAI …) — ถ้าข้อมูลเป็นความลับ ให้ใช้โมเดลภายในองค์กร (Ollama ผ่าน Base URL) หรือไม่ใช้
- เนื้อหาในเซลล์เป็นข้อมูลไม่น่าเชื่อถือ (prompt injection): prompt ระบบสั่งไม่ให้ทำตามคำสั่งที่ฝังมา และเครื่องมือเขียนมีเฉพาะการสร้างแดชบอร์ด/วิดเจ็ต (ไม่มีเครื่องมือแก้/ลบข้อมูลในตาราง)
- จำกัด 20 ข้อความ/นาที/ผู้ใช้, สูงสุด 8 รอบเครื่องมือต่อคำสั่ง
- ประวัติแชตเก็บในเบราว์เซอร์ของผู้ใช้ (localStorage) เท่านั้น
- ยังไม่ได้ทดสอบกับ API จริงของผู้ให้บริการทั้ง 3 ราย (ทดสอบแค่ type-check) — ชื่อโมเดลตั้งค่าเองได้ในแผง
